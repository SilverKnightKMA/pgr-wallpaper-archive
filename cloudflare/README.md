# Random wallpaper endpoint (Cloudflare Worker)

Returns a **302 redirect to a random wallpaper** hosted on
`raw.githubusercontent.com` (the archive's own copies — never the Kuro CDN).

| URL | Result |
|---|---|
| `https://blog.tungvuthanh.com/pgr-wallpaper-archive/wallpapers` | random (all) |
| `https://blog.tungvuthanh.com/pgr-wallpaper-archive/desktop` | random desktop |
| `https://blog.tungvuthanh.com/pgr-wallpaper-archive/mobile` | random mobile |

Query params: `?server=jp|cn|global|tw|kr` (filter by server), `?preview=1`
(lightweight `.jpg` preview instead of the full image).

The Worker reads `docs/index-data.json` from the GitHub Pages site (regenerated
automatically by `src/generate_readme.py` on every archive batch) and
edge-caches it for 6 hours.

## Deploy (one-time, ~5 minutes)

1. **Push this repo to `main` first** — the Pages site must be serving
   `index-data.json` (`https://blog.tungvuthanh.com/pgr-wallpaper-archive/index-data.json`
   should return JSON) before the Worker will work.

2. Cloudflare dashboard → **Workers & Pages → Create → Worker**, name it e.g.
   `pgr-random`, **Deploy**, then **Edit code** and paste the contents of
   `worker.js` → **Deploy**.

3. Worker → **Settings → Domains & Routes → Add → Route**, zone
   `tungvuthanh.com`, and add these 3 routes:

   ```
   blog.tungvuthanh.com/pgr-wallpaper-archive/wallpapers*
   blog.tungvuthanh.com/pgr-wallpaper-archive/desktop*
   blog.tungvuthanh.com/pgr-wallpaper-archive/mobile*
   ```

   (Narrow routes only — every other path of the Pages site bypasses the
   Worker completely.)

4. Test:

   ```bash
   curl -sI https://blog.tungvuthanh.com/pgr-wallpaper-archive/desktop | grep -i location
   # expect: location: https://raw.githubusercontent.com/.../desktop/....png
   curl -sI "https://blog.tungvuthanh.com/pgr-wallpaper-archive/wallpapers?server=jp&preview=1" | grep -i location
   # expect: location: https://raw.githubusercontent.com/.../previews/....jpg
   ```

## Notes

- Free tier is plenty (100k requests/day; each hit is one redirect).
- `index-data.json` is regenerated by the archive pipeline on every batch, so
  new wallpapers enter the random pool automatically after the next run.
- If you ever remove the Worker, the 3 URLs simply fall back to GitHub Pages
  (404) — nothing else is affected.
