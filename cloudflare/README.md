# Random wallpaper endpoint (Cloudflare Worker)

Live at **`https://pgr-random.tungvt1912.workers.dev`** (workers.dev
subdomain). Optionally also add the 3 routes on `blog.tungvuthanh.com` below
if you want the URLs under the blog domain.

## Behavior

**Default — returns image BYTES** (the first response IS the image,
`content-type: image/jpeg|png`), so it works with every client including
tools that do not follow redirects:

| URL | Result |
|---|---|
| `https://pgr-random.tungvt1912.workers.dev/wallpapers` | random image (all) |
| `https://pgr-random.tungvt1912.workers.dev/desktop` | random desktop |
| `https://pgr-random.tungvt1912.workers.dev/mobile` | random mobile |

Query params:

- `?server=jp|cn|global|tw|kr` — restrict to one server
- `?preview=1` — serve the lightweight `.jpg` preview instead of the full image
- `?redirect=1` — **302 redirect** to `raw.githubusercontent.com` instead of
  proxying bytes (client downloads directly from GitHub's CDN; fastest path
  for browsers/`curl -L`)

The Worker streams the upstream image through untouched (never buffers),
forwards `Range` requests (206 passthrough), and always serves GitHub-hosted
URLs — the archive's own copies on `raw.githubusercontent.com`, never the
Kuro CDN.

Data source: `docs/index-data.json` on the GitHub Pages site (regenerated
automatically by `src/generate_readme.py` on every archive batch),
edge-cached for 6 hours. Each request picks a fresh random image.

## Deploy / update (one-time, ~5 minutes)

1. The Pages site must be serving `index-data.json`:
   `https://blog.tungvuthanh.com/pgr-wallpaper-archive/index-data.json`
   should return JSON.

2. Cloudflare dashboard → **Workers & Pages → Create → Worker**, name it
   `pgr-random`, **Deploy**, then **Edit code** and paste the contents of
   `worker.js` → **Deploy**. (Updating later = Edit code → paste → Deploy.)

3. Test:

   ```bash
   curl -s -o /dev/null -w '%{http_code} %{content_type} %{size_download}B\n' \
     https://pgr-random.tungvt1912.workers.dev/desktop
   # expect: 200 image/jpeg <bytes>
   curl -sI "https://pgr-random.tungvt1912.workers.dev/wallpapers?redirect=1" | grep -i location
   # expect: location: https://raw.githubusercontent.com/...
   ```

4. (Optional) To also serve the paths under the blog domain, add routes
   (Worker → Settings → Domains & Routes → Add → Route, zone
   `tungvuthanh.com`):

   ```
   blog.tungvuthanh.com/pgr-wallpaper-archive/wallpapers*
   blog.tungvuthanh.com/pgr-wallpaper-archive/desktop*
   blog.tungvuthanh.com/pgr-wallpaper-archive/mobile*
   ```

   Narrow routes only — every other path of the Pages site bypasses the
   Worker completely.

## Notes

- Free tier is plenty (100k requests/day).
- `index-data.json` is regenerated by the archive pipeline on every batch, so
  new wallpapers enter the random pool automatically after the next run.
- Removing the Worker just disables the 3 URLs — nothing else is affected.
